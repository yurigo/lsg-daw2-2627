# Hello Vite

This project builds on the `hello-clases` animation and packages it as an ES
module application using Vite and the p5.js instance mode API. Run `pnpm
install`, then `pnpm dev` in this folder and open the local URL shown in the
terminal. Use `pnpm build` to create the production bundle.

## Files

- `index.html` is Vite's HTML entry point. It loads `src/main.js` and provides
  `#app` as the p5.js canvas container; `#calendar` is an unused placeholder.
- `src/main.js` imports the CSS and dependencies, defines the p5 sketch, and
  creates the p5 instance.
- `src/pelota.js` exports the reusable `Pelota` class.
- `src/counter.js` exports a separate click-counter example; it is not imported
  by the current entry point.
- `src/reset.css` contains global reset rules; `src/style.css` sets the body
  font.
- `.gitignore` excludes dependency directories, build output, logs, and local
  editor files.
- `eslint.config.js` configures ESLint's JavaScript/browser and CSS rules.
- `package.json` declares Vite, p5.js, ESLint, and the project scripts.
- `pnpm-lock.yaml` is generated by pnpm to preserve dependency versions.
- `public/` contains static icons, and `src/assets/` contains image assets.

## Instance mode and modules

`main.js` imports `Pelota` and p5.js. The `sketch(p)` function receives the p5
instance as `p`; p5 drawing functions and canvas properties are accessed
through that object, such as `p.createCanvas`, `p.width`, and `p.random`. This
instance mode avoids relying on p5 functions as global variables and makes the
sketch's dependency explicit.

p5 calls `p.setup` once and `p.draw` repeatedly. Setup creates the canvas and
initial ball. Each draw clears the canvas, draws the ball collection, updates
their positions, and draws a red ball at the pointer. `p.mouseClicked` creates
and stores another ball. `new p5(sketch, document.querySelector("#app"))`
constructs the p5 instance and attaches its canvas to the selected element.

The class is similar to the one in `hello-clases`, except it receives and stores
the p5 instance. Thus `Pelota` uses `this.p5.random`, `this.p5.fill`,
`this.p5.circle`, and canvas dimensions from the correct instance.

**EXTRA — unused counter:** `setupCounter(element)` in `counter.js` keeps a
counter in a closure, updates the element's text, and registers a click event
listener. It is not wired into the page. It uses `innerHTML` for a fixed
text-only string; when displaying untrusted user content, prefer `textContent`.

**EXTRA — CSS reset:** `reset.css` applies global defaults, including
`box-sizing: border-box`, removes margins, scales media to its container, and
sets inherited form-control fonts. The `prefers-reduced-motion` media query
limits an animation-related style to users who have not requested reduced
motion.
